Weekly Analyst

An autonomous data analyst for a CSV that is replaced every week. It decides on its own whether anything material changed, stays silent when nothing did, and otherwise writes a stakeholder PDF. It runs on a 1B model, on CPU, with no data leaving the machine.

MiniCPM-V 4.7 1B, f16 (no quantization)llama.cpp, CPU onlyread-only on the sourcea person approves before anything is sent

What the agent does each week

  1. Extract only the columns it needs from the new CSV, read-only, with size and format limits.
  2. Validate and detect with deterministic code: schema changes, then a ranked blend of detectors under a weekly alert budget. Nothing material means no model call and no report.
  3. Plan and investigate. The model picks follow-up checks from a fixed menu (named, parameterised queries first, free SQL last) inside a locked-down query engine.
  4. Draft. The model writes words only. Code supplies every number, chart and table.
  5. Check. A separate implementation recomputes every number in the PDF. Any mismatch, unlisted number or unsafe PDF object stops the run.
  6. Approve. The report waits for a person. Approval re-renders the stamped PDF, re-checks it, and only then sends it.

Real reports from the real model

Produced by this exact code with the f16 model on a 2-core Colab CPU, then approved with the real approve command. The data is synthetic sales data: eight identical weeks, then a changed week. Each run took about 3 minutes.

Run it yourself

This is a static page because free Hugging Face hardware no longer runs Gradio apps without a PRO plan. The whole project is in this repository, including a Gradio app that runs the real agent on a free CPU:

git clone https://huggingface.co/spaces/ewin-reg/weekly-analyst
cd weekly-analyst
pip install -r requirements.txt
python app.py        # opens the demo; the first run downloads the 2 GB model

To host it live, duplicate this Space, set sdk: gradio in the README and choose CPU hardware.
